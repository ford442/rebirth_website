# ReBirth RB-338 Website Structure Plan

This document breaks the curated ReBirth resource collection into website sections and content elements.

## 1. Downloads Page

### Tabs / sections
- **Mods (.rbm)**
  - Primary curated hub: Peff’s ReBirth Mod Archive
  - Direct featured downloads and descriptions
  - Bulk archive links (GitHub, Archive.org)
  - Highlighted categories: SP-1200, Amen DnB, reversed 808, Oberheim SEM, experimental mods

- **Songs (.rbs)**
  - Primary curated hub: Peff’s ReBirth Song Archive
  - Featured ZIP bundles and notable tracks
  - Organize by compatible mod or genre
  - Add a short compatibility note for each track bundle

### Recommended content elements
- Quick setup note: “Requires ReBirth v2.0.1 (free ISO on Archive.org). Test in compatibility mode if needed.”
- Warning callout: “Old files may require legacy OS/compatibility layers and could behave differently than modern DAWs.”
- Legal note: “These are community/fan-preserved archives. Respect original copyrights.”

## 2. Community & Extras Page

### Sections to include
- **ReMaker 1.32**
  - Explain it extracts `.rbs` MIDI / automation / arrangement data.
  - Link to Archive.org pack and mention modern DAW utility.

- **Hardware / modern twist**
  - LMNC ReBirth physical controller video and coverage.
  - Note how the controller turns ReBirth into a tactile acid machine.

- **Merch & nostalgia**
  - Fan-made ReBirth T-shirt link.
  - Historical Propellerhead official shirt note.

- **Legacy community hubs**
  - ReBirth Corner nostalgia site.
  - ReBirth for iPad legacy app.
  - Other fan utilities from peff.com.

## 3. Content organization strategy

### Suggested grouping
- **Mods by type**
  - Classic vintage-style mods
  - Drum kit / sample mods
  - Experimental / weird mods
  - Mod-specific song collections

- **Songs by compatibility and genre**
  - RedStripe-dnb / Amen DnB
  - Acid / techno / house
  - Demo / effects packs
  - Mod-linked bundles

### User-facing labels
- “Curated downloads” for hand-picked direct links
- “Bulk archives” for large collections and GitHub mirrors
- “Modern companion tools” for ReMaker and hardware
- “Nostalgia extras” for merch, articles, and vintage utilities

## 4. Implementation notes

- Prefer descriptive cards or list items for each resource with:
  - Name/title
  - Type (`.rbm`, `.rbs`, utility, archive)
  - Short description
  - Compatibility / notes
  - Verified link

- Use a separate section for “Why ReBirth v2.0.1?” with direct Archive.org search guidance.
- Keep the site authentic by mentioning the late ’90s / early 2000s fan archive era.
- Emphasize Peff.com as the primary curated source.
- Include a dedicated resource roundup page covering:
  - Software download sources
  - Mod archives
  - Song archives
  - Tools and utilities
  - Hardware controllers
  - Merch, videos, and modern DAW integration notes
  - History, articles, and key scene personalities
  - A deep preservation analysis page for digital archaeology, executable integrity, `.rbs` archival recovery, and cultural legacy

## 5. Future refinements

- Add a “Recommended mod + song pairings” section.
- Include a “How to use ReMaker with modern DAWs” note once verified.
- Expand the archive with community-submitted `.rbs` / `.rbm` content.
- Consider a “Dead link audit” note for future maintenance.
