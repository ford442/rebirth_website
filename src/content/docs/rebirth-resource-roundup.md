## 4. TOOLS & UTILITIES

### ReMaker (RBS to MIDI Converter)

- **What:** Converts ReBirth RBS 2.0 songs to Standard MIDI Format (SMF) and vice versa
- **By:** NordBeat Multimedia (also mentioned as TG Virus on peff.com)
- **Site:** https://nordbeat.com/remaker
- **Download:** https://nordbeat.com/download-center#remaker
- **Features:** Converts TB-303 notes, slides, filter EG, panning, volume, accent, shuffle, TR-909 flam
- **Also available from:** MNX2010 site (32/64 bit versions for Win 7/8/10/11)

### ModPacker

- **What:** The official tool (on ReBirth CD) for creating your own .rbm mods
- **Requires:** 50+ JPEG image files + AIFF audio files assembled into a mod
- **Included with:** ReBirth RB-338 installation CD in the "ModPacker" folder

### Knob Construction Kit

- **What:** Photoshop 5 layered files for creating mod knob graphics
- **By:** Kurt Kurasaki (peff)
- **Size:** 8.0MB ZIP
- **Link:** Available from https://www.peff.com/rebirth/

### Filetyper Utilities (MacOS 8/9)

- **Prop Drop** -- restores RBS/RBM file type/creator codes
- **RBS and RBM Filetyper** -- drag-and-drop file type fixer
- **ReBirth 2.0 Mod AIFF File Renamer** -- converts 1.5 mod filenames to 2.0 format
- **All available from:** https://www.peff.com/rebirth/

### Special RBS Files from peff.com

- **PlaySamp.RBS** -- triggers every sample in a mod sequentially (great for rendering out mod samples)
- **UltraPan** -- hacked panning codes for 32nd-note stereo panning effects
- **UltraTweak** -- flips waveform switches on 303 modules for timbre variation
- **"ReBirth of the Cool" tutorial songs** -- from Keyboard Magazine July 2000 article

## 5. HARDWARE & PHYSICAL CONTROLLERS

### Sam Battle's ReBirth Hardware Controller (Look Mum No Computer)

- **What:** A fully custom-built hardware MIDI controller with real switches and potentiometers mapped to every ReBirth parameter
- **Built by:** Sam Battle (Look Mum No Computer)
- **Video:** https://www.youtube.com/watch?v=Cs99PS-OXLk (and related videos)
- **Articles:**
  - https://sonicstate.com/news/2023/05/31/rebirth-rb-338-hardware-controller/
  - https://www.musicradar.com/news/look-mum-no-computer-rebirth-controller
  - https://www.synthforbreakfast.nl/rebirth-reborn-as-a-hardware-synthesizer/

### AudioPilz's "$15,000 Hardware ReBirth"

- **What:** YouTuber AudioPilz recreated the entire ReBirth setup using real vintage Roland hardware: 2x TB-303, TR-808, TR-909, plus hardware effects
- **Video:** https://www.youtube.com/watch?v=VmXdOLQxqII ("I built ReBirth FOR REAL and this Happened")
- **Article:** https://www.musicradar.com/news/youtuber-tries-to-create-classic-rebirth-software-as-hardware
- **Used:** Cyclone Bass Bot TT-303 (as 2nd 303), E-RM Multiclock for sync, hardware preamps, 24-track mixing
- **Verdict:** "It is time for Roland to set ReBirth free"

### ReBirth Input Machine (Reason)

- **What:** The ReBirth Input Machine in Reason allows routing all 18 ReBirth audio channels through Reason's mixer via ReWire
- **Note:** Only works with 32-bit Reason (versions up to 8.1). Requires ReWire registry configuration.

### Yamaha MIDI Remote Template

- **What:** Official template for controlling ReBirth via Yamaha AW2816 hardware
- **Link:** https://usa.yamaha.com/support/updates/52072_en.html

## 8. ABOUT "RESLICE"

**Reslice is NOT a ReBirth-specific tool.** It's a separate iOS app:

- **ReSlice** by VirSyn -- an audio slicer with 4-part sequencer and multi-effects for iOS
- **Context:** It gets mentioned alongside ReBirth because both are used for acid/techno production on iOS. Some producers use ReSlice to chop loops and ReBirth (or Troublemaker) for 303 basslines, syncing via Ableton Link.
- **Links:** Available on the App Store; reviewed at Music App Blog

If you were looking for loop-slicing tools to use WITH ReBirth, this is it. If you were looking for something else called "Reslice" in the ReBirth context, it may be a misremembered name -- the closest actual ReBirth tools are:

- **ReMaker** (RBS to MIDI)
- **ReCycle** (Propellerhead's loop slicer -- now FREE from Reason Studios as of 2025!)
- **ReWire** (the audio/MIDI sync protocol between ReBirth and Reason/Cubase)

## 9. MODERN DAW INTEGRATION NOTES

### Running ReBirth Today

- **Windows 10/11:** Use the 64-bit installer from archive.org + WinHelp32 patch (KB917607)
- **Mac:** Use Classic Mode on older OS X, or emulators like QEMU/SheepShaver
- **Linux:** There was a Linux remake called "Reborn" (faced legal challenges, hard to find)

### ReWire Gotchas

- ReBirth is 32-bit only, so it only ReWires with 32-bit host applications
- For 64-bit DAWs: use a ReWire 32-to-64-bit bridge or loopMIDI + ReWire workaround
- ReWire X64 bridge can help sync ReBirth with modern Reason
- **Detailed guide:** https://francisfisher.me.uk/problem/2015/how-to-use-reason-with-rebirth-rb-338-on-64-bit-windows-7-or-8/

### Alternatives When ReBirth Won't Work

- **TAL BassLine 101** -- excellent 303 emulation
- **D16 Phoscyon** -- 303 VST
- **D16 Drumazon** -- 909 VST
- **D16 Nepheton** -- 808 VST
- **Behringer TD-3 / MS-101** -- hardware 303/101 clones
- **Cyclone Analogic Bass Bot TT-303** -- hardware 303 clone
